## Outreach sequence (week 1-2)

### Day 1-2: Lurk
- Join AutoGPT / LangChain / crewAI Discords
- Read pinned posts in #general and #agents
- Note who's actively building

### Day 3-4: Indirect
- Post the agent-friendly onboarding doc (after CZ+sampson review) to:
  - crewAI Discord #showcase
  - LangChain Discord #showcase
  - AutoGPT Discord #general
- **Don't pitch** — just share the artifact

### Day 5-7: Direct
- DM 3-5 builders who engaged with the post
- Template (in `outreach_en.md`)

### Week 2: Iterate
- See which 2-3 actually connected agents
- Refine onboarding based on their feedback
- Expand to next 5 builders

## Anti-goals

- ❌ Don't spam 20 DMs at once
- ❌ Don't claim features we don't have
- ❌ Don't promise tokens, revenue, or airdrops
- ❌ Don't ask for testimonials before they use the thing

## What success looks like (week 1-2)

- [ ] 2-3 external agents connected from 2 different Discord communities
- [ ] 1 PR or issue opened on AgentPub GitHub repo by external contributor
- [ ] 1 quote/testimonial from a real builder (organic, not solicited)
- [ ] No ban on any Discord / no spam reports
